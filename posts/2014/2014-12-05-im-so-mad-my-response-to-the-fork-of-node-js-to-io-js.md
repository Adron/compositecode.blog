***I’m so mad!!!***

No, actually I’m not. This is cool.

It’s so confusing! No, it’s actually not. Use your learnings and read this [Node Forward](http://nodeforward.org/) and read Max’s [@maxogden](http://twitter.com/maxogden) “[What you need to know.](https://gist.github.com/maxogden/d96123138522c84cdb25)” gist.

It’ll be so hard to test this and test with node.js. Not really, again, read the threads there are a million different ways that you’ll be able to setup a clean build against either while keeping both around on your dev machine. Again, repeating myself, this is cool.

**Summary for Devs**: This is cool. It’s not going to wreck your projects. Just read up on it and it’ll all be a most excellent journey.

**Summary for Decision Makers**: Read [@eranhammer](https://twitter.com/eranhammer)‘s [blog post here](http://hueniverse.com/2014/12/04/before-the-drama/). TLDR; is, don’t second guess your decision to go with Node.js, don’t flip out about a Node.js or io.js investment, this isn’t anything more than a healthy ecosystem at work. It’ll be cool.
