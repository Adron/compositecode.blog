## [Webinar](http://blog.jetbrains.com/webstorm/2014/02/webinar-node-js-development-workflow-in-webstorm/): Node.js Development Workflow in WebStorm

This coming week I’m doing an intro to work and flow with Node.js JavaScript Programming that I’m working with [JetBrains](http://www.jetbrains.com/) on. In the webinar I’ll be covering the following key topics in the webinar:

- Open an existing project & getting WebStorm configured for running, testing and related working tasks.
- A quick tour of other IDE features that help with daily work. Some in pretty huge ways.
- Running WebStorm & debugging Node.js JavaScript applications.
- Checking out Mocha, how it works and what it gives WebStorm the power to do. Then we’ll write a few tests & implement that code too.

All this will include Q & A throughout and at the end of the webinar. Be sure to [register](http://info.jetbrains.com/WebStorm-Webinar-Registration-20022014.html) soon!
