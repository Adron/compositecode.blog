I usually don’t post two blog entries in one day, but I had so much to rattle on about it seemed like a rule to break.

## DeployCon, Cloud Expo and Cloud Bootcamp

I’ll be speaking at the [Cloud Bootcamp](http://cloudcomputingbootcamp.com/general/bootcampagenda.htm) at the Cloud Expo in New York City. So if you’re coming to the conference, swing by and let’s talk PaaS and the future of software development and cloud computing. I’m looking forward to the event, it’ll be a good time and has a lot of educational content.

Also during Cloud Expo, be sure to check out the DeployCon. The DeployCon Conference is a PaaS Conference put together by Rishidot Research. Check out more information [here](http://www.deploycon.com/).

## Iron Foundry

Over on the [Iron Foundry Project](http://ironfoundry.org/) we’re going to be putting together some new material on what’s next, where we are on the project and where we are headed. The effort will be pushing forward with some possible *hackathons* or *installathons* for those interested. So if anyone is keen on checking out the latest and greatest of .NET PaaS options available, send me an e-mail and we’ll start coordinating some efforts.
