## A New Kind of User Group…  Coders Unite Pt 2!

Call it a hackathon, coder session, workshop, or whatever. What it is not, is a presentation. What am I talking about? A user group effort that I’m working, and mentioned recently regarding [coders uniting](/2012/02/02/getting-things-done-coders-unite/), on with others that will be centered around doing something, a range of things, during a specific time frame, to expand one’s knowledge, skills, or help mentor on the specific thing that is being worked on. Instead of me going on and on with an explanation, I’ll describe a scenario from this new user group.

**[![](/images/adronhall.smugmug.com/Software/Meetups-N-Conferences/Coders-Society/i-prF8kDx/0/O/Screen-Shot-2012-02-25-at.png)](http://codersociety.org)**

***Vote, Group, Create!***

First a conversation kicks off a thread ([sign up to kick off a thread yourself](http://groups.google.com/group/coder-society)). From that thread a topic arrises that people want to work with, work on, learn more about, and try to implement. Recently one of these topics that has come up is [Continuous Deployment](http://continuousdelivery.com/). The idea has been batted around now for a few weeks and it is ripe for a meet up and for a group to get together and actually implement a solution. This is a perfect example of something that can be implemented in a set time, with a group of people, individuals can then take that knowledge and go forth to make their development shops better.

So join the e-mail list, help us come up with ideas, and we’ll see you at an upcoming meet up and we’ll build something awesome!

- Github Account:  <https://github.com/organizations/CoderSociety>
- Coder Society:  <http://codersociety.org>
