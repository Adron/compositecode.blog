Got some excellent coding and systems setup coming up in the next few days. Also a meetup on the 28th with Tim Kellogg and Alena Hall presenting on some interesting topics around distributed database data working on Kubernetes and WebAssembly of the hot temperament type. A new surprise guest addition on my Twitch channel that is scheduled to swing into Valhalla and help build out a cluster and respective needed DHCP, DNS, and related configuration for a setup on the *metal*!

## Schedule

- **![thrashing-code-csharp](/wp-content/uploads/2018/08/thrashing-code-csharp.jpg)[TODAY @ 3:33pm – Thrashing Code Session A004 C# Environment Variable Chaos Resolved?](https://www.twitch.tv/events/rN9_gd8lQqKDowDXwUcEyg)** – In this session, I’m planning to have the environment variable issues with .NET core figured out, so I’ll provide those. Then we’ll dive into actually getting something built in that black box.
- **![adding-ssl](/wp-content/uploads/2018/08/adding-ssl.jpg)[August 23rd 10:00am DataStax Academy Twitch Stream](https://www.twitch.tv/datastaxacademy/events)** – This session will include David and I as we dig into the Killrvideo Reference Application and discuss the pull request with the SSL additions to the code base. We’ll talk through the changes, why they’ve been made, and what advantage they provide for deployment into a multi-cloud environment.
- ![thrashing-code-systems-config](/wp-content/uploads/2018/08/thrashing-code-systems-config.jpg)[**August 24th 1:30pm~*ish* – Systems Configuration Setup and Cluster Setup**](https://www.twitch.tv/events/e-0fzoBKQmaWsUYBlHzkuQ) on the metal! – This session will include a guest who’s going to step in and help in setup and configuration of a 5 node cluster of systems plus bastion server. Join for a how-to of setup, configuration, and clustering details.
- **![thrashing-code-gopher](/wp-content/uploads/2018/08/thrashing-code-gopher.jpg)[August 24th, 3:33pm – Go Coding on Colligere](https://www.twitch.tv/events/rN9_gd8lQqKDowDXwUcEyg)** – In this session I’ve finally gotten to the point where I can start filling out some of the CLI functionality. I’ll be adding over the next few days items to the issues list on Github too. Feel free to add content, or related items to the issue log too!
- ![speakers](/wp-content/uploads/2018/08/speakers.png)[**August 28th, 6:30pm – Operators and Developers of Distributed Systems**](https://www.meetup.com/Seattle-Scalability-Meetup/events/253849473/) – Two presentations are lined up for this meetup:  “[Extreme Temperature WebAssembly!](https://www.meetup.com/Seattle-Scalability-Meetup/events/253849473/)” by [Tim Kellogg](https://twitter.com/kellogh) and “[So You Want To Run a Data-Intensive System On Kubernetes](https://www.meetup.com/Seattle-Scalability-Meetup/events/253849473/)” by [Alena Hall](https://twitter.com/lenadroid).
- **![thrashing-code-csharp](/wp-content/uploads/2018/08/thrashing-code-csharp.jpg)[August 31st, 3:33pm – More Go, More Feature Additions](https://www.twitch.tv/events/rN9_gd8lQqKDowDXwUcEyg)** – This session isn’t 100% clarified and ready just yet. But I’ll be there, ready to sling some more Go code and get more features done, more code refactored, and progress made.
