Just a few links for today.  I am still hustling together some code for the Kata that I am working up related to real world testing – ala TDD.  In the meantime, check out some cloud tidbits.

- Eugenio Pace mentions the release of the [Windows Azure Architecture Guide Part 1](http://blogs.msdn.com/eugeniop/archive/2010/05/19/windows-azure-architecture-guide-part-1-complete-starting-part-2.aspx).  [Download it on the Codeplex Site](http://wag.codeplex.com/releases/view/45438).
- The other really good download on Codeplex, is the Windows [Azure](http://www.microsoft.com/windowsazure) Security Guidance Project.  The patterns and practices group put this out and it has some really good material.  The key members on this project are JD Meier ([Data Security Scenarios on Azure](http://blogs.msdn.com/jmeier/archive/2010/05/19/data-security-scenarios-on-azure.aspx)) and Paul Enfield.  Definitely check out [JD Meier’s Blog](http://blogs.msdn.com/jmeier/) if you are doing Azure Development, it is a must read.
- [David L](http://blogs.msdn.com/davidlem/) wrote up a good blog entry on [WCF, REST, and URL Rewriting with Windows Azure](http://blogs.msdn.com/davidlem/archive/2010/04/26/wcf-rest-and-url-rewriting-with-windows-azure.aspx).
- If you’re interested in [Parallel Programming](http://www.microsoft.com/downloads/details.aspx?familyid=86B3D32B-AD26-4BB8-A3AE-C1637026C3EE&displaylang=en) also be sure to check out the [guide David L references](http://www.microsoft.com/downloads/details.aspx?familyid=86B3D32B-AD26-4BB8-A3AE-C1637026C3EE&displaylang=en) in his latest entry, [Getting Started with Parallel Programming](http://blogs.msdn.com/davidlem/archive/2010/05/15/getting-started-with-parallel-programming-in-net-4.aspx).
- Also if you are just getting into Cloud Development with Azure check out this [Fire Starter](http://blogs.msdn.com/windowsazure/archive/2010/05/18/windows-azure-firestarter-sessions-now-available-on-demand.aspx).  Excellent links to get started with.
