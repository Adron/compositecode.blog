[![](https://photos.adron.me/Software/Misc-Images/Just-Icons-and-Bits/i-Z6fMHBP/0/S/logo_jetbrains1-S.png)](http://www.jetbrains.com/)Like any good open source project, a good continuous integration server is fundamental to a smooth workflow for everyone. I’ve always been a big advocate of [Team City](http://www.jetbrains.com/teamcity/) from [JetBrains](http://www.jetbrains.com/). With the versatility of the their build server it could be used for Junction and prospectively more in the future as projects started up and expanded. The only issue I ran into immediately was, where can I get some resources to run Team City on?

[![](https://photos.adron.me/Software/Misc-Images/Just-Icons-and-Bits/i-vC8qtgK/0/O/tier3.gif)](http://www.tier3.com)Immediately I pinged my friend Jared Wray [@jaredwray](http://twitter.com/jaredwray) over at [Tier 3](http://www.tier3.com) to see if there might be some options. He immediately was into the idea, being interested in the Junction Project itself and an advocate of Riak himself it was a perfect fit. Jared ok’d and the [Tier 3](http://www.tier3.com) team got some access setup to get a Team City build server running for the Junction Project.

I dove into setting up the build server at [Tier 3](http://www.tier3.com) and as of this moment have a solid green light showing a good build! Thanks to Jared and the [Tier 3](http://www.tier3.com) team for helping out, we’re all looking forward to slinging some code and getting a nice open source project in Junction.

[![](https://photos.adron.me/Software/Software-Development/Estuary-Project/i-sBPcjJW/0/O/Dashboard%20Goodness.jpg)](http://adron.github.io/junction/)Over the next few days I’ll also be providing a number of blog entries (the final touches are getting wrapped up right now!) on how I went about setting up Team City, server issues I ran into and the troubleshooting I did to get .NET 4.5 to work specifically for the Junction Application. In the end I’ve gotten a Windows 8 Store Application, using C# building successfully on Team City using NuGet and other key features.

For a quick how-to of setting up Team City check out “[TeamCity Setup for Junction Build, Plus Implosions](/2013/09/24/teamcity-setup-for-junction-build-plus-implosions/)“.

For more information on the Junction Project check out “[Windows 8 Logos, Badges, Splash Screens of Riak](/2013/08/09/windows-8-logos-badges-spash-screens-of-riak/)“, the “[Introducing Junction](/2013/08/20/introducing-junction/)” and “[Junction Two Week on Tuesdays Bi-weekly Review : Issues #001](/2013/09/03/junction-two-weeks-on-tuesday-bi-weekly-review-issue-001/)“).
