I’ve really been doing tons of hard core dev work with some of the newer .NET 3.0 technologies lately.  The project that is underway currently has been utilizing the WCF (Windows Communication Foundation) since it was beta and the SCSF (Smart Client Software Factory) since the first real CTP.  Those two foundations I have felt that the real technology utilization of .NET 3.0 was only halfway completed.  That notion being planted in my head, I’ve begun a trek to tie together the other parts of .NET 3.0 such as the WPF (Windows Presentation Foundation) and WF (Windows Workflow).  For that trek I use the following development tools, libs, factories, foundations, etc.

The following items are what I have installed for my development efforts:

1. ReSharper – [ReSharper](http://www.jetbrains.com/resharper/) is one of the, if not the most kick ass product for cleaning up, writing solid, keeping things formatting, intellisense enhancing, beautiful code helper application on the market!  This product is produced and sold by [JetBrains](http://www.jetbrains.com).  I highly suggest going on getting this product.
2. EntLib (Enterprise Library) – [Application Blocks](http://www.codeplex.com/entlib) baby!!!  These rule.  If you’re building an application for an environment that could even remotely be considered “Enterprise” you should seriously consider using these.  If you aren’t, you’re most likely doing something VERY wrong.
3. WCSF (Web Client Software Factory) – The [WCSF](http://www.codeplex.com/websf) is very helpful when building web applications with dedicated horizontally developing teams.  Check it out, you might find it useful for even non-horizontally aligned teams.
4. Guidance Automation – The [Guidance Automation Toolkits](http://msdn2.microsoft.com/en-us/teamsystem/aa718948.aspx) assist with templates and such for things like the Smart Client Software Factory, Web Client Software Factory, and other such foundations.  These can be very helpful to reduce those initial setup of code files for the mentioned foundations.
5. Cropper – [Cropper](http://www.codeplex.com/cropper) is a screen shot utility, been around for a while, been pointed out by dozens of developers, very helpful little utility with very little overhead!  This is the way helper applications should work!
6. dotnetfx3 – [Download](http://www.microsoft.com/downloads/details.aspx?FamilyId=10CC340B-F857-4A14-83F5-25634C3BF043&displaylang=en) it, code with it, love it.
7. WPF & WCF Extensions – [WF Extensions](http://www.microsoft.com/downloads/details.aspx?FamilyID=e8232f93-48f0-4e74-b09d-b51f1d4231a4&displaylang=en) and [WPF/WCF Extensions](http://www.microsoft.com/downloads/details.aspx?FamilyId=F54F5537-CC86-4BF5-AE44-F5A1E805680D&displaylang=en) are rather vital to modern .NET 3.0 Development.  Download and install these already!
8. WF Extensions – As mentioned above, [WF Extensions](http://www.microsoft.com/downloads/details.aspx?FamilyID=e8232f93-48f0-4e74-b09d-b51f1d4231a4&displaylang=en) are vitally important and awesome!
9. Easymock.NET – [Easymock](http://sourceforge.net/projects/easymocknet/) is an easy dll lib that can be added to projects to do mock testing.  If you aren’t really familiar with mock testing I’ll have some posts on site soon, but until then check out the [download](http://sourceforge.net/projects/easymocknet/) and hit up [Google](http://www.google.com/) with “[mock unit tests](http://www.google.com/search?q=mock+unit+tests)” and you’ll have a plethora of things to read up on.

For Windows XP vs. Vista CTP releases and compatibilities check out the [MSDN Site write up](http://msdn2.microsoft.com/en-us/windowsvista/aa904955.aspx).
