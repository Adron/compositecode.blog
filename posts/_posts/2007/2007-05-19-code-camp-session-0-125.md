So I went to hit up my second session which is about XNA Development.  I caught the tail end of the [Speech Server Session](http://blogs.msdn.com/mithund/archive/2007/05/17/portland-code-camp-v3-0-see-you-there.aspx#comments) ([Code Camp Link](http://pdx.techevents.info/codecamp/3/presenterinfo.aspx?id=30db390b-0c76-4592-aaeb-89f872dfea49)) by [Mithun Dhar](http://blogs.msdn.com/mithund/default.aspx).  In hat short 10 minute tail end of that I must say I am very interested in the voice recognition, the Windows Workflow, and other features he was using within the Visual Studio IDE to build out the call/voice application.  Very quick, very smooth, and very useful for any company that wants to streamline the call in or other needs in that spectrum.  I’ll be looking into this more in the near future.
