I came upon the need to mount an ISO image to the local OS, often I’ve done this on a running VM image, but that is built in.  On the native Microsoft OS there really isn’t a setup to do this.

To the rescue comes [Magic ISO Maker](http://www.magiciso.com/tutorials/miso-magicdisc-overview.htm).  I first noticed it via a [blog entry on Rich Mercer’s site](http://richmercer.com/blog/mounting-iso-images-in-vista-5536/).  So if you need to mount an ISO image or even multiple ISO images to a box, this is the software to do it.
