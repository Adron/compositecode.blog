I went to the session on [Microsoft Silverlight Analytics Framework](http://msaf.codeplex.com/) ([MSAF](http://msaf.codeplex.com/)) today while here at MIX 2010.  It was a great walk through the features, ideas, and what the end goal is.  [Michael Scherotter](http://blogs.msdn.com/synergist/) did a great job of lining up the ideas, intentions, and the functional ideas behind the framework.

The framework is built around the [Silverlight](http://www.microsoft.com/silverlight) Behaviors.  If you aren’t sure what behaviors are, check out these entries from [Nikhilk.net Silverlight Behaviors](http://www.nikhilk.net/Silverlight-Behaviors.aspx), [Silverlight 3 Drag Behavior](http://joel.neubeck.net/2009/07/silverlight-3-drag-behavior/), [An Introduction to Behaviors, Triggers, and Actions](http://blogs.msdn.com/expression/archive/2009/03/23/an-introduction-to-behaviors-triggers-and-actions.aspx), and of course the [MSDN Documentation on the matter](http://msdn.microsoft.com/en-us/library/cc221408(VS.95).aspx).

Some of the key features of the framework is to support out-of-browser scenarios, which works perfectly with out [Webtrends](http://www.webtrends.com) [DX](http://developer.webtrends.com) Web Services.  Offline scenarios, which again, we have worked toward supporting at [Webtrends](http://www.webtrends.com) [DC](http://developer.webtrends.com/community/dc/) Web Services via caching and other criteria as needed.  Another feature that I was really stoked about is the [Microsoft Expression Blend](http://www.microsoft.com/expression/products/Blend_Overview.aspx) integration that removes the need for coding, thus simplifying the addition of analytics components based on events or other actions within a [Silverlight](http://www.microsoft.com/silverlight) Application.  This framework also easily supports A/B Testing (again, something we do quit a bit of at [Webtrends](http://www.webtrends.com) with [Webtrends Optimize](http://www.webtrends.com/Products/Optimize).

The last thing I really wanted to point out was the control support that this framework has support in already from [Telerik RadControls](http://msaf.codeplex.com/wikipage?title=Telerik%20RadControls&referringTitle=Home), [Smooth Streaming Media Element](http://www.microsoft.com/downloads/details.aspx?FamilyID=2b1ce605-3b99-49ad-8a26-1250f2acbbf6&displayLang=en), and [Microsoft Silverlight Media Framework Player 1.0](http://smf.codeplex.com/).  These are implemented with behaviors and handlers exposed via [MEF](http://mef.codeplex.com/) (Managed Extensibility Framework).

All in all, great second day, great analytics framework for [Silverlight](http://www.microsoft.com/silverlight), and great presentation.  Until tomorrow, adieu.
