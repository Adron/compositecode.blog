Even though I left Webtrends well over 6 months ago, I still regularly talk to a number of my cohorts there.  I also still talk to a number of customers who I became friends with over my years with the company.  I was contacted recently by a couple of those contacts asking if the posts I made or the SDK I helped put together were still available.  I went to searching and I found the following blog entries that I had put together while at Webtrends.  In addition I did find a link to the [Webtrends DX .NET SDK](https://developer.webtrends.com/docs/DOC-1182).  I however would check with someone at Webtrends as to if it is supported or has been kept up to date.  Either way, it provides a great resource for a starting point in accessing the Webtrends DX RESTful APIs.

- [SDK ADO .NET DataTable and DataSets and Code Bits](https://developer.webtrends.com/community/dx/blog/2009/10/23/sdk-adonet-datatabledataset-and-code-bits)
- [Getting Compression on Reporting Web Services](https://developer.webtrends.com/community/dx/blog/2009/04/01/requesting-compression-on-reporting-web-services)
- [Connecting to Webtrends Web Services](https://developer.webtrends.com/community/dx/blog/2009/03/12/connecting-with-net-to-webtrends-web-services)

Webtrends DX .NET SDK

- [Webtrends DX .NET SDK](https://developer.webtrends.com/docs/DOC-1182)
