I recently did a clean install of Windows 7 64-bit.  It had been a really long time since I listed the current tools, SDKs, and frameworks that I’ve been using.  Thus here’s my entourage of software that I use on a regular basis that is installed on my primary development machines.

**Basic Software & System OS**

- Windows 7 64-bit
- Visual Studio 2010 Ultimate
  - [ReSharper 5.1](http://www.jetbrains.com/resharper/)
  - Visual Studio 2010 Plugins
    - [VS Code Map](http://visualstudiogallery.msdn.microsoft.com/en-us/1c54d1bd-d898-4705-903f-fa4a319b50f2)
    - [Productivity Power Tools](http://visualstudiogallery.msdn.microsoft.com/en-us/d0d33361-18e2-46c0-8ff2-4adea1e34fef)
    - [PowerCommands for Visual Studio](http://visualstudiogallery.msdn.microsoft.com/en-us/e5f41ad9-4edc-4912-bca3-91147db95b99)
    - [Regex Editor](http://visualstudiogallery.msdn.microsoft.com/en-us/55c24bf1-2636-4f94-831d-28db8505ce00)
    - [Dev Color (Color Picker)](http://visualstudiogallery.msdn.microsoft.com/en-us/7dbae8b3-5812-490e-913e-7bfe17f47f1d)
    - [NuGet](http://visualstudiogallery.msdn.microsoft.com/en-us/27077b70-9dad-4c64-adcf-c7cf6bc9970c)
  - [Gallio](http://www.gallio.org/) (w/ [mbUnit](http://www.mbunit.com/))
  - [NBuilder](http://nbuilder.org/) (for building up test data for in memory SQLite)
  - [TestDriven.NET](http://www.testdriven.net/)
  - [SQLite](http://www.sqlite.org/) for [.NET with Design Time](http://sqlite.phxsoftware.com/)
  - [Rhino Mocks](http://www.ayende.com/projects/rhino-mocks/)
  - [Windows Azure SDK 1.3](http://www.microsoft.com/downloads/en/details.aspx?FamilyID=7a1089b6-4050-4307-86c4-9dadaa5ed018)
  - [Windows Azure AppFabric](http://www.microsoft.com/downloads/en/details.aspx?FamilyID=39856a03-1490-4283-908f-c8bf0bfad8a5&displaylang=en)
  - [AWS (Amazon Web Services) SDK 1.2](http://aws.amazon.com/net/)
  - Inversion of Control Containers:  [Autofac](http://code.google.com/p/autofac/) & [Castle Project Windsor](http://stw.castleproject.org/Windsor.MainPage.ashx)
  - [Elmah](http://code.google.com/p/elmah/downloads/list)
  - [Topshelf](http://topshelf-project.com/) for WCF Deployment
- Expression Ultimate 4
- Office 2010 (Rarely, I try to stick to Google Docs, to maintain usability across devices)

**Administration Utilities**

- [Virtual Clone Drive](http://download.cnet.com/Virtual-CloneDrive/3000-20432_4-173879.html) (For mounting \*.iso images)
- [FileZilla](http://filezilla-project.org/) for FTP
- [VirtualBox](http://www.virtualbox.org/wiki/Downloads) for Virtualization
- [WinRar](http://www.rarlab.com)

**Themes & Such**

- [Stardock](http://www.stardock.com/)‘s [WindowBlinds](http://www.stardock.com/products/windowblinds/)
- [Visual Studio Color Theme Editor](http://visualstudiogallery.msdn.microsoft.com/en-us/20cd93a2-c435-4d00-a797-499f16402378) (Visual Studio Plugin) w/ [Blend Theme](http://www.nerdpad.com/visual-studio/visual-studio-2010-dark-expression-blend-color-theme) ([download](http://www.nerdpad.com/wp-content/uploads/2010/04/Expression_ColorScheme.zip))
- [Visual Studio Style Embers](http://studiostyl.es/schemes/embers)

In addition to these packages of software another as important, if not more important to my day-to-day software development includes these software services and cloud hosting services.

**SaaS, PaaS, and IaaS**

- [Highrise HQ](http://highrisehq.com/) by [37signals](http://37signals.com/)
- [Unfuddle](http://unfuddle.com/) Project Management with [Git Fast Version Control System](http://git-scm.com/)
- [Github](https://github.com/) for Sharing Source & Open Source Projects
- [Gmail](http://www.gmail.com), [Gdocs](http://docs.google.com), and [Gcal](https://www.google.com/calendar) by [Google](http://www.google.com/)
- [Smugmug](http://www.smugmug.com/) for image hosting
- [Amazon Web Services](http://aws.amazon.com) EC2, S3, and other services
- [Windows Azure](http://www.microsoft.com/windowsazure) Web Roles, Table, Blog, and other Storage & Service
