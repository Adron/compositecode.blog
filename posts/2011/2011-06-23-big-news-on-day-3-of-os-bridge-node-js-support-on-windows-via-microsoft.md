This, being the explosion of support for Node.js, is excellent news. This further enables JavaScript for the whole stack, on any operating system stack. Getting a good solid, stable, and supported version on Windows will enable some serious performance on that platform. Up until the release of the support, Node.js is primarily limited to Windows via software called CYGWIN, which emulates (or runs on?) Windows and simulates a Unix/Linux Environment.
