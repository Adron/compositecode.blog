Some top database providers for various open source databases like MariaDB, PostgreSQL, MongoDB, Apache Cassandra, Redis, Elasticsearch, and Neo4j:

1. **MariaDB:**
   - [Amazon RDS for MariaDB](https://aws.amazon.com/rds/mariadb/)
   - [Google Cloud SQL for MariaDB](https://mariadb.com/products/skysql/google-cloud-platform/)
   - [Microsoft Azure Database for MariaDB](https://azure.microsoft.com/en-us/products/mariadb/)
   - [MariaDB via SkySQL](https://mariadb.com/products/skysql/) (deploys to multiple clouds)
2. **PostgreSQL:**
   - [Amazon RDS for PostgreSQL](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/CHAP_PostgreSQL.html)
   - [Google Cloud SQL for PostgreSQL](https://cloud.google.com/sql/docs/postgres/introduction)
   - [Microsoft Azure Database for PostgreSQL](https://azure.microsoft.com/en-us/products/postgresql/)
   - [Aiven for PostgreSQL](https://aiven.io/postgresql)
   - [ScaleGrid for PostgreSQL](https://scalegrid.io/postgresql/)
   - [Neon PostgreSQL](https://neon.tech/) (cool integration [here](https://neon.tech/blog/neon-vercel-integration) and [here w/ Vercel integration](https://vercel.com/blog/introducing-the-vercel-ai-sdk))
3. **MongoDB:**
   - [MongoDB Atlas](https://www.mongodb.com/atlas)
   - [Google Cloud MongoDB](https://cloud.google.com/mongodb)
4. **Apache Cassandra:**
   - [DataStax Astra (Cassandra as a service)](https://www.datastax.com/products/datastax-astra)
   - [Aiven for Apache Cassandra](https://aiven.io/cassandra)
   - [Instaclustr for Apache Cassandra](https://www.instaclustr.com/education/apache-cassandra-database/)
5. **Redis:**
   - [Redis Labs (Redis Enterprise)](https://redis.io/docs/about/redis-enterprise/)
6. **Elasticsearch:**
   - [Amazon Elasticsearch Service](https://aws.amazon.com/opensearch-service/)
   - [Elastic Cloud](https://www.elastic.co/cloud/)
   - [Aiven for Elasticsearch](https://aiven.io/opensearch)
   - [Bonsai Elasticsearch](https://bonsai.io/)
7. **Neo4j (Graph Database):**
   - [Neo4j Aura (cloud-based service)](https://neo4j.com/cloud/platform/)
