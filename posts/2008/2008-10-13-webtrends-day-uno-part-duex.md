Day number one has started off well.  I've landed an awesome 2.66 Ghz Quad Core, 10GB RAM, 64-bit workstation and have started installing all of the necessary software.  It looks like I'll be doing a bit of what I've been wanting to do for a while, which is branch out and see some of the Java world.  One of the things that is on my main to do list is to get Eclipse installed and running for Java Development efforts.

Over the next couple weeks I'll be diving into some meetings and getting my feet on the ground for what projects are in the queue and what project priorities are.  It's nice to be on this side of the paradigm at WebTrends this time.  Don't get me wrong, it was awesome working in client services before, building cubes, troubleshooting the product, and building the various custon one of solution for customers but it's definitely nice to dig into the innards of the code base!
