The basic idea behind this talk was to bring the attendees through a quick history of Visual Studio Code, .NET’s compatibility across operating systems and then a quick dive into a few samples and different tools that help people to use the tooling, languages, and capabilities of .NET across all of these systems.

## Prerequisites to Follow Along

- [![](/wp-content/uploads/2015/06/ah_f_256.png)](/wp-content/uploads/2015/06/ah_f_256.png)I shouldn’t even have to write this, but install [Git](https://git-scm.com/).
- [OS-X](https://www.apple.com/osx/), [Ubuntu](http://www.ubuntu.com/), and [Windows](http://www.microsoftstore.com/store/msusa/en_US/cat/Windows-8.1/categoryID.62684800) (At least, these are the operating systems I’ve tested the presentation code on – specifically OS-X Yosemite, Ubuntu Server/Desktop 14.04.2 LTS, and Windows 8.1)
- [Visual Studio Code](https://code.visualstudio.com/) – [Getting Started with Visual Studio Code](https://code.visualstudio.com/Docs/setup)
- Check out [OS-X and F# [Clone It, Build It, Install It, Hack It]](/2015/05/07/os-x-and-f-clone-it-build-it-install-it-hack-it/) and [Simplifying bash & repl Use With F#](/2015/05/15/simplifying-bash-repl-use-with-f/) for more information on setting up and using [F# on non-Windows Platforms](/2015/05/10/why-f-and-why-not-windows/) (and Windows to some degree).
- Also I’ve started a series on F# which includes a lot of the troubleshooting and steps I took to get things running on the various operating systems; “[\_\_\_\_\_\_\_1 |> F# – Getting Started, Thinking Functionally (Notes)](/2015/06/16/_______1-f-getting-started-thinking-functionally/)“, “[\_\_\_\_\_\_11 |> F# – Some Hackery – A String Calculator Kata](/2015/06/22/______11-f-some-hackery-a-string-calculator-ka/)” and “[\_\_\_\_\_\_10 |> F# – Moar Thinking Functionally (Notes)](/2015/06/24/______10-f-moar-thinking-functionally-notes/)” are the articles that are most parallel to the presentation.
- Some of the issues I discussed are available on [Stack Overflow](http://www.stackoverflow.com/) titled “[How can I resolve the “Could not fix timestamps in …” “…Error: The requested feature is not implemented.”](http://stackoverflow.com/questions/30972220/how-can-i-resolve-the-could-not-fix-timestamps-in-error-the-requested)” and “[ProjectScaffold Error on Linux Generating Documentation](http://stackoverflow.com/questions/30992501/projectscaffold-error-on-linux-generating-documentation)“
- Even though [these are primarily prerequisites focused around having Node.js and JavaScript working](https://github.com/ThrashingCode/nodejs-training-prerequisites) on your machine they’re also extremely helpful to have installed for a number of reasons, such as using yo as a scaffold builder for F# Projects and such.
