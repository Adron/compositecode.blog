*Octocat o’ Github*

Since Github doesn’t have a follow on organizations, I set out to put this list together for great projects. Here’s the current list as it stands. If you’d like to add to this list, just hit up the [Google Docs Worksheet](https://docs.google.com/spreadsheet/ccc?key=0AjzoXvTKg56mdHZENEVBVV9rVWoyWU9feThSVWtXZVE) we’ve been working from. Cheers!
