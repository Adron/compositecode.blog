The [GraphQL Foundation](https://graphql.org/) is of course, the core organization responsible for GraphQL. Their priority is development and maintenance of the [GraphQL Specification](https://spec.graphql.org/). They also provide resources around [learning](https://graphql.org/learn/), [code libraries](https://graphql.org/code/), [community](https://graphql.org/community/), a [FAQ](https://graphql.org/faq/), and [news](https://graphql.org/blog/).

This page is currently \*under construction\*. The contents will eventually be focused around these specific categories.

## GraphQL Projects and Related Projects

- ***The core*** [GraphQL Project](https://github.com/graphql)
- [PostGraphile](https://www.graphile.org/) – Extensible high-performance automatic GraphQL API for PostgreSQL.
- [quicktype](https://quicktype.io/) ([Github](https://github.com/quicktype/quicktype)) – Convert JSON into typesafe code in any language.
- [Schemathesis](https://github.com/schemathesis/schemathesis) – is a specification-based testing tool for OpenAPI and GraphQL apps based on the [Hypothesis](https://hypothesis.works/) framework.
- [Microcks](https://microcks.io/) – OSS Kubernetes Native tool for API mocking and testing.
- [gqt](https://github.com/eerimoq/gqt) – Build and execute GraphQL queries in the terminal.
- [GraphQL Armor](https://github.com/Escape-Technologies/graphql-armor) – security layer for Apollo/Yoga/Envelop based servers.

## Companies focused on GraphQL

- [The Guild](https://the-guild.dev) – This is an organization that offers [services](https://www.the-guild.dev/services) and provides a long list of open source software focused around building out GraphQL solutions.
  - [Code Generator](https://the-guild.dev/graphql/codegen) – Generation of typed queries, mutations, subscriptions, and typed GraphQL resolvers.
  - [Tools](https://the-guild.dev/graphql/tools) – is a set of NPM packages and an opinionated structure for how to build GraphQL schema and resolvers in JavaScript, following the GraphQL-first development workflow.
  - [Stitching](https://the-guild.dev/graphql/stitching) – automatically stitch multiple schemas together into one larger API in a simple, fast, and powerful way.
  - [Hive](https://the-guild.dev/graphql/hive) – Prevent breaking changes, monitor performance of your GraphQL API, and manager your API gateway.
  - [Conductor](https://the-guild.dev/graphql/gateway) – All in one API gateway.
  - [Inspector](https://the-guild.dev/graphql/inspector) – Validate schemas and detect changes. Receive schema change notifications. Keep operation and fragments consistent.
  - [ESLint](https://the-guild.dev/graphql/eslint/docs) – integrates GraphQL and ESLint for better developer experience.
  - Config – One configuration for all your GraphQL tools.
  - [Helix](https://www.graphql-helix.com/) – Build your own extensible and framework-agnostic GraphQL Server.
  - [Shield](https://www.graphql-helix.com/) – GraphQL permissions framework for complex authorization systems.
  - [Yoga](https://the-guild.dev/graphql/yoga-server) – A fully-featured, simple to set up, performant, and extendable server.
  - [Modules](https://the-guild.dev/graphql/modules) – Enterprise grade tooling for your GraphQL server.
  - [Envelop](https://the-guild.dev/graphql/envelop) – Develop and share plugins that are usable with any GraphQL server framework or schema.
  - [Mesh](https://the-guild.dev/graphql/mesh) – A fully-featured GraphQL gateway framework.
  - [Scalars](https://the-guild.dev/graphql/scalars) – Common custom GraphQL Scalars for precise type-safe GraphQL schemas.
  - [SOFA](https://the-guild.dev/graphql/sofa-api) – Generate RESTful APIs from your GraphQL Server.
  - [WhatsApp Clone](https://github.com/Urigo/WhatsApp-Clone-Tutorial) – A repo showing off the various “The Guild” ecosystem libraries and tooling.
- [AWS AppSync](https://aws.amazon.com/appsync/) – provides a robust, scalable, GraphQL interface for application developers to combine data from multiple sources, including Amazon DynamoDB, AWS Lambda, and HTTP APIs.
- [Hasura](https://hasura.io/) – Instant GraphQL on all your data.
- [Apollo](https://www.apollographql.com/) – The GraphQL developer platform.
- [Fauna DB](https://fauna.com/) – A GraphQL native database.
- [Wundergraph](https://wundergraph.com/) – an all-in-one solution to build, integrate, deploy and monitor modern APIs.

## Companies with tangential focus on GraphQL

- [DataStax Astra DB](https://www.datastax.com/products/datastax-astra) – DataStax Astra DB is a service that provides GraphQL as a means to access the underlying Apache Cassandra databases for their database as a service solutions.
- [MongoDB Atlas](https://www.mongodb.com/atlas) – MongoDB Atlas service is a database as a service that provides GraphQL as a means to access the underlying Mongo Databases.
