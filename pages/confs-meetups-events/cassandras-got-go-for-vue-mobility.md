**Abstract:** Go is an open source programming language that makes it easy to build simple, reliable, and efficient software. Vue.js is a progressive and lightweight framework for building user interfaces. Both of these technologies grow in popularity every day. And compared to other monolithic languages or frameworks, are designed to be incrementally adoptable amongst developers.

In this presentation, Adron Hall and Cristina Veale will talk about these two technologies and how they integrate with Apache Cassandra and DataStax Enterprise. They’ll show you how Go and Vue.js—when paired together—make a powerful, yet elegant, solution for your development needs.

**Key takeaways include:**

- Delving into patterns and practices
- Discuss disparate IDEs like [VS Code](https://code.visualstudio.com/) and [JetBrains GoLand](https://www.jetbrains.com/go/)
- Utilizing [DataStax Academy Twitch](https://www.twitch.tv/datastaxacademy) to stream our dev progress
